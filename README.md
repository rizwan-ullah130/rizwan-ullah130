### ⚙️ How I Work on a Dataset

1. **Understand the business question** before touching the data
2. **Inspect the data** — columns, data types, missing values, duplicates
3. **Clean only what's needed** and document every change
4. **Explore (EDA)** to find patterns, trends, and outliers
5. **Visualize** with charts that answer a specific question
6. **Report insights and recommendations** in simple, non-technical language
