## 🔄 How I Work on a Dataset

1. **Understand the business question** before touching the data
2. **Inspect the data:** columns, data types, missing values, duplicates
3. **Clean only what is needed** and document every change
4. **Explore (EDA)** to find patterns, trends and outliers
5. **Visualize** with charts that answer a question
6. **Report insights and recommendations** in simple language
